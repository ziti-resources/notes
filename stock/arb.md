Starting from <b>OOS15.0.0.1301(EX01)</b>, OnePlus has introduced Anti-Rollback Protection (ARB). \
Which means we can not downgrade OxygenOS once we flash this version, doing so will result in a <b>hard brick</b>

Always check your OxygenOS version before unlocking bootloader and/or flashing ROMs \
You have to use the full-OTA zip of that specific version in case of bootloops or reverting back to OxygenOS
